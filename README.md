# 🔐 Password Generator (Python)

A simple Password Generator written in Python.

## Features

- Generate random passwords
- User chooses the password length
- Uses:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters

## Technologies

- Python 3

## How to Run

bash
python main.py


## Example


Enter password length:
12

Generated Password:
A#8qLm!2P@x9
